# Git Practice Project

**Author:** Safi

## Project Overview

This project demonstrates Git and GitHub fundamentals, including repository initialization, commits, branches, merging, and pushing code to a remote repository.

## Features

- Display the author's name and current date.
- Perform basic calculator operations.
- Handle invalid calculator inputs.
- Demonstrate Git branching and merging.

## Technologies

- Python
- Git
- GitHub

## How to Run

Run the following command from the project root:

    python src/main.py
